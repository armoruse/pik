# 打包與裝置工具

本目錄保存既有維護環境使用的工具副本。工具各依其原始授權，PikminX 的授權不取代工具授權。

- [Apktool 2.10.0](https://github.com/iBotPeaches/Apktool)：APK 資源與 Smali 重組。
- [Uber APK Signer](https://github.com/patrickfav/uber-apk-signer)：對齊、簽章與驗證；授權資訊保留在 JAR 內。
- [Google Platform-Tools](https://developer.android.com/tools/releases/platform-tools)：Windows ADB 與 DLL；隨附 NOTICE.txt。

Java 17 需另行安裝。原手機更新簽章的私鑰不包含在本目錄。
