## 安裝與驗證

安裝時需在 Android 設定中允許瀏覽器或檔案管理員「安裝未知應用程式」。

## 功能與操作指標

### 1. 自動換花
- **設定流程**：
  1. 開啟 PikminX 應用程式，設定換花門檻數量。
  2. 在懸浮設定中，先選擇顏色，再透過下拉選單新增花朵，並利用上下按鈕排列觸發順序。
  3. 勾選風險確認，進入 Android 系統設定開啟「PikminX 自動換花」無障礙服務。
  4. 切換至遊戲內，開啟「種花選單」並保持置頂，從懸浮窗點擊「開始」。
- **觸發邏輯**：
  - **初始狀態**：若尚未種花，系統自動選擇第一個可用花瓣並點擊「開始種花」。
  - **切換條件**：僅當「目前剩餘數 ≤ 門檻」且「候選花瓣數量 > 門檻」時觸發切換。
  - **選取機制**：依賴使用者設定的允許清單順序，並優先利用遊戲原生搜尋功能切換花瓣。

### 2. 自動收集明信片
- **設定流程**：
  1. 遊戲畫面停留在欲收藏的花朵詳細頁面。
  2. 從懸浮窗切換至「收集明信片」分頁。
  3. 設定收集次數 (1–15 次)、目標花盆名稱及每次派出的皮克敏數量 (1–5 隻)。
  4. 點擊「開始收集」。
- **辨識與執行機制**：
  - **鎖定目標**：透過 OCR 鎖定詳細頁上方的「明信片地點名稱」(忽略下方花種文字)。地圖花朵圖示在未點擊前沒有文字，先以裝置端像素找出花冠候選，再由 OCR 驗證點擊後顯示的花名。所有頁面與文字按鈕皆以 OCR 判斷。
  - **花瓣頁匹配**：僅點選與設定名稱「完全相同」且數量「≥ 80 片」的花盆。若未見目標，最多向下滑動 12 次。當連續兩次 OCR 畫面無變化即判定到底並停止。
  - **皮克敏選擇**：將遊戲排序設為「喜愛」。若系統自動選滿 5 隻，助手將由後往前取消至使用者設定的數量。需連續兩次 OCR 確認數量無誤後，才會點擊 GO 並點擊「接收」。
  - **完成判定**：OCR 確認畫面已離開接收頁面後，才計入完成次數。達到設定次數後立即停止運作。連續多次執行將受當時地圖花朵與遊戲版面影響。

## 隱私、限制與風險

- **零權限要求**：本工具未宣告網路、定位、相機、帳號讀取或儲存空間權限。
- **資料隔離**：OCR 模型完全打包於 APK 內，所有畫面辨識皆在裝置端完成，不會上傳任何資料。
- **環境限制**：自動搜尋優先使用遊戲的無障礙節點。若搜尋欄無法安全輸入或結果無法確認將自動停止，不執行盲目捲動。遊戲更新介面版型可能導致辨識區域失效，需等待工具適配。
- **帳號風險**：**使用第三方自動化工具違反遊戲服務條款，可能導致遊戲帳號遭到警告、暫時停權或永久停權。請務必確認已知悉此風險。**
