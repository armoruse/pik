# PikminX

PikminX 是一個以 Android 無障礙服務為基礎的 Pikmin Bloom 輔助工具原始碼專案。

應用程式的主要程式碼與資源檔案，不包含完整 Android Studio 建置設定、Gradle wrapper、測試程式或 APK。

## 功能

目前程式碼包含以下自動化功能：

- 自動換花
  - 透過 OCR 辨識花盆名稱與剩餘花瓣數量
  - 依照使用者設定的花朵順序進行切換
  - 支援花盆搜尋與選取確認

- 自動收集明信片
  - 尋找符合條件的花盆
  - 自動使用花瓣取得明信片
  - 自動選擇指定數量的皮克敏
  - 支援收集進度與失敗停止機制

- 探險派遣
  - 辨識探險清單中的水果與花盆
  - 支援水果、花盆或混合目標
  - 支援自動選擇或拖曳選擇皮克敏
  - 透過多次畫面確認降低誤點風險

- 探險返回物品收取
  - 辨識返回畫面的水果與花盆
  - 自動收取回程物品
  - 可設定明信片的接收或捨棄方式
  - 連續無物品或達到安全時間上限時停止

- 懸浮窗控制
  - 在遊戲畫面上顯示控制懸浮窗
  - 提供開始、暫停與停止操作
  - 顯示目前自動化狀態與錯誤訊息
  - 支援自動換花、明信片、探險派遣及回程收取等模式

## 運作方式
PikminX 使用 Android AccessibilityService：
1. 讀取 Pikmin Bloom 的畫面與視窗事件。
2. 透過 OCR、畫面分析與節點辨識判斷目前遊戲狀態。
3. 在確認畫面符合預期後執行點擊或手勢。
4. 如果畫面無法確認、操作失敗或遊戲離開前景，系統會停止目前流程。

## 使用前注意事項
PikminX 需要使用 Android 無障礙服務，因此可能具備以下能力：
- 讀取遊戲畫面與視窗內容
- 擷取螢幕畫面
- 執行點擊與滑動手勢
- 顯示其他應用程式上方的懸浮窗

請只在你了解上述權限與自動點擊風險的裝置上使用。

遊戲介面、文字或座標變更可能造成辨識失敗或自動化流程停止。
### 使用前請確認你了解相關風險，並自行判斷是否符合遊戲服務條款。
