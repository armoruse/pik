# PikminX

PikminX 是 Pikmin Bloom 的 Android 輔助工具，協助執行換花、明信片收集及派遣收取。

## 風險

- PikminX 不是 Pikmin Bloom 官方工具。使用第三方自動化工具可能違反遊戲規範，導致警告、暫停或永久停權；帳號風險由使用者自行承擔。
- 啟用無障礙服務後，Android 會允許 PikminX 讀取指定遊戲視窗的文字與互動元件，並執行點擊、輸入及滑動。請只在自己信任的裝置上啟用。
- 使用前請確認遊戲畫面、花瓣數量、花盆名稱、派遣目標與操作次數；新裝置或新版本建議先執行一次、一次只設定少量次數。
- 請保持螢幕開啟、Pikmin Bloom 在前景，並避免讓懸浮窗遮住遊戲按鈕。發現畫面不符、流程卡住或狀態無法辨識時，立即按「暫停」或停止服務。
- 請只從可信來源取得 APK。側載 APK 代表你必須自行確認檔案來源、簽章與完整性。

## 使用方式

1. 安裝 APK；最低支援 Android 11（API 30）。
2. 開啟 PikminX，閱讀風險提示並勾選確認。
3. 開啟 Android「無障礙設定」，啟用 PikminX；需要時再顯示懸浮窗。
4. 開啟 Pikmin Bloom，手動進入相應頁面，再從懸浮窗選擇功能。

### 自動換花

1. 在設定中設定花瓣低於多少片時切換，並依使用順序加入花朵。
2. 在 Pikmin Bloom 開啟種花選單。
3. 從懸浮窗的「自動換花」分頁按「開始」。

PikminX 會使用遊戲搜尋框尋找設定中的花盆，確認選取結果與數量後才繼續；無法確認時會停止。

### 收集明信片

1. 先在遊戲中開啟要收集的花朵詳細頁。
2. 在「收集明信片」分頁設定收集次數（1–15 次）、花盆與每次使用的皮克敏數量（1–5 隻）。
3. 按「開始收集」，等待每輪完成或查看懸浮窗狀態。

花盆選項來自 APK 內建清單；PikminX 會確認頁面、花盆、皮克敏數量及接收結果，無法確認時會停止。

### 派遣收取

1. 在遊戲中進入探險清單並完整展開。
2. 在「派遣收取」分頁設定次數（1–99 次）、目標、選取方式與皮克敏類型。
3. 新裝置建議先設定 1 次，確認畫面與結果正確後再增加次數。
4. 按「開始派遣」；找不到目標、頁面不明或結果無法確認時，流程會停止。

## 隱私

- PikminX 不宣告網路、定位、相機或外部儲存空間權限；程式沒有上傳截圖或 OCR 文字的功能。
- 截圖、像素分析與 OCR 在裝置端處理。OCR 模型隨 APK 提供，辨識結果只用於目前的自動化流程。
- 使用者設定會儲存在 App 私有的 SharedPreferences，內容包含門檻、花朵順序、花盆、次數與皮克敏數量；PikminX 不要求或儲存 Pikmin Bloom 帳號密碼。
- 無障礙服務啟用期間，PikminX 仍可讀取 Pikmin Bloom 視窗內容並執行手勢。這項權限本身仍屬敏感權限，請在不使用時停用。
- 主畫面的社群與贊助按鈕只有在使用者點擊後才會交由系統瀏覽器或其他 App 開啟；開啟後的資料處理依該外部服務自己的隱私政策為準。
- 若不再使用，請先停止自動化、關閉 PikminX 無障礙服務，再解除安裝；也可從 Android App 設定清除本機設定資料。
